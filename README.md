# KanjiBuildUp

手入力やCSVで自分の問題を追加できるSwiftUIの漢字学習アプリです。選定モックアップ `output/mockups/04-notebook-gothic-white.png` を基準に、白に近い背景、緑のアクセント、システムのゴシック体を使用しています。

## 起動

`KanjiBuildUp.xcodeproj` をXcodeで開き、`KanjiBuildUp` スキームでiPhoneシミュレーターまたは実機を選択して実行してください。iOS 17以降を対象としています。このプロジェクトは作成時からXcodeの新形式 `project.xcproj` を使用しています。

初回は空の漢字帳です。一覧右上の「追加」→「CSV取り込み」からファイルを選び、プレビューと件数を確認して取り込みます。確認用ファイルは `Samples/kanji.csv` です。実機ではFilesアプリで参照できる場所に置いてください。

## 手入力

一覧右上の「追加」→「手入力で追加」から1件ずつ登録できます。カテゴリー・問題・答えは必須、意味は任意です。カテゴリーは候補から選ぶか、新しい名前を入力できます。前後の空白は除去し、空白のみの必須項目では追加できません。

保存すると「がんばるぞ」として一覧に追加されます。保存に失敗した場合は入力を残して理由を表示します。入力途中のキャンセルでは破棄するかを選べます。

カテゴリー候補は「当て字」「書き」「音読み」「訓読み」「ことわざ」「四字熟語」の順で表示します。登録済みの独自カテゴリーも候補に追加されます。

## CSV形式

```csv
カテゴリー,問題,答え,意味
読み,桜,さくら,春に花を咲かせる木。
四字熟語,一期一会,いちごいちえ,一生に一度の出会いを大切にすること。
```

- ヘッダー必須。4列の順序は変更できます。
- UTF-8（BOMあり・なし）およびShift JIS。上限5MB。
- 引用符で囲んだカンマ・改行、二重引用符のエスケープに対応。
- カテゴリー、問題、答えは必須。意味は空欄可。
- すべて「がんばるぞ」で追加されます。再取り込みは追加扱いで、重複排除や上書きはしません。
- 不正なCSVは全体を取り込まず、理由を表示します。

## 学習

カテゴリーと習熟度の組み合わせで絞り込めます。「問題をはじめる」は表示範囲をランダムに1巡します。開始時の問題集合を固定するので、学習中に習熟度を変更しても問題は飛びません。

「答えを見る」で答えと意味を表示し、習熟度を選択してから「次の問題」で進みます。最後は「学習を終える」で完了画面に進みます。一覧の項目から直接開くと答えが表示され、「一覧に戻る」で終了します。

データはアプリ内のApplication Support/KanjiBuildUp/items.jsonに保存します。書き込みに失敗した場合は変更を確定せずエラーを表示します。読み込みに失敗したファイルは上書きしません。外部サーバーやアカウントは使いません。

## 編集・備考・削除

問題・答え画面では標準のナビゲーションバーを使い、左端から右へのスワイプでも一覧に戻れます。
右上の「…」→「編集」からカテゴリー・問題・答え・意味・備考・覚え具合を変更できます。「保存」で確定し、入力途中のキャンセルでは破棄確認を表示します。

「備考を追加／編集」からも同じフォームを開けます。備考は答え画面で確認できます。以前の保存データは備考を空欄として読み込み、CSVの4列仕様は変更していません。

削除は右上の「…」→「削除」で確認してから実行します。削除後は学習を終了して一覧に戻ります。保存に失敗した場合は元のデータを保持します。

## ソース構成

```text
KanjiBuildUp/
├── App/                 アプリのエントリーポイント
├── Models/              問題・習熟度・学習セッション・エラー
├── Services/            CSVのデコードと解析
├── Stores/              学習データの状態管理と永続化
├── Features/
│   ├── Library/         一覧・絞り込み・画面遷移
│   ├── Study/           出題・答え・習熟度変更
│   ├── Import/          CSV選択とプレビュー
│   ├── ManualEntry/     手入力の入口
│   └── Editing/         新規登録・編集の共通フォーム
├── UI/
│   ├── Theme/           共通色と習熟度の表示色
│   └── Components/      共通ボタンと習熟度バッジ
└── Assets.xcassets/     アセット
```

画面固有のUIは各Feature内、複数画面で使う部品はUI/Componentsに置きます。Models・Services・StoresはSwiftUIに依存しません。保存処理はLearningStore、CSV形式の変更はKanjiCSVに集約しています。Xcodeのフォルダー参照で配下のSwiftファイルを自動的にターゲットへ追加します。

## 検証

データ処理テスト:

```sh
xcrun swiftc KanjiBuildUp/Models/*.swift KanjiBuildUp/Services/*.swift KanjiBuildUp/Stores/*.swift Tests/LearningTests.swift -o /tmp/kanji-tests
/tmp/kanji-tests
```

UIテストはXcodeのProduct > Test、または以下で実行します。

```sh
xcodebuild -project KanjiBuildUp.xcodeproj -scheme KanjiBuildUp -destination 'platform=iOS Simulator,name=iPhone 17 Pro,OS=26.5' test
```

UIテストはDEBUG限定の環境変数で独立した保存先とCSVプレビューを用意し、取り込み確定・学習・保存を確認します。OSのファイル選択画面自体はこのfixtureテストの対象外です。
